# 🛡️ 金融詐騙偵測系統

使用 AI 機器學習技術保護您的帳戶安全的詐騙偵測網站。

## 功能特性

✨ **實時詐騙偵測**
- 關鍵字匹配系統 - 識別常見詐騙用語
- 隨機森林機器學習模型 - 多維度風險評估
- 交易行為分析 - 檢測異常交易模式

🎯 **多維度風險評估**
- 📧 訊息內容分析
- 💰 交易金額檢查
- 🌙 半夜交易偵測
- ⚡ 高頻轉帳識別

📊 **詳細檢測報告**
- 偵測到的詐騙關鍵字
- 文字風險分數
- 隨機森林判定機率
- 視覺化風險進度條

## 技術棧

**後端**
- Flask - Web 框架
- scikit-learn - 機器學習
- pandas - 資料處理

**前端**
- HTML5 - 結構
- CSS3 - 樣式設計
- JavaScript - 互動功能

## 安裝和執行

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 執行應用

```bash
python app.py
```

### 3. 開啟網站

在瀏覽器中訪問：
```
http://localhost:5000
```

## 使用方式

1. **輸入訊息** - 貼上您收到的可疑訊息
2. **填寫交易資訊** - 輸入金額和交易特徵
3. **開始檢測** - 點擊檢測按鈕
4. **查看結果** - 獲得詐騙風險評估

## 常見詐騙特徵

🚨 要求立即操作或轉帳  
🚨 要求提供 OTP 或帳戶密碼  
🚨 聲稱帳戶異常需要驗證  
🚨 提供不明連結或要求點擊  
🚨 承諾高額投資報酬  
🚨 半夜或短時間內多次轉帳要求  

## 安全建議

✓ 向官方客服確認交易真偽  
✓ 不要點擊陌生連結  
✓ 不要分享 OTP 或驗證碼  
✓ 使用複雜密碼並定期更換  
✓ 開啟二次認證 (2FA)  
✓ 保持警惕心態

## 模型說明

### 關鍵字匹配系統
檢測常見詐騙關鍵字：
- 帳戶異常
- 立即盜證
- 轉帳
- OTP
- 登入
- 連結
- 投資
- 退款

### 隨機森林分類器
考慮因素：
- 交易金額
- 是否為半夜交易
- 是否短時間內多次轉帳
- 訊息文字風險分數

## 免責聲明

本系統提供的檢測結果僅供參考，不作為法律或金融建議。在進行任何金融交易前，請向官方機構確認。
